## 🔭 What I'm building

### ♻️ [SnapPick](https://github.com/adyhafetz/snappick)
A community recycling app for Perak, Malaysia (Android).
Residents photograph household waste, an **on-device YOLOv8n (TFLite)** model identifies the material, and a community collector can claim the pickup.

- Offline-first scanning across 7 material classes
- Privacy by design: exact addresses stay private, collectors see grid-snapped pins
- Admin-driven retraining loop on Kaggle so the detector improves over time
- Expo / React Native app, Next.js admin and public dashboards, Supabase backend

### 🚀 [Internify](https://github.com/adyhafetz/internify)
An autonomous AI resume-tailoring agent and Telegram copilot.
Send a job link and get back a tailored, ATS-friendly, 1-page LaTeX resume grounded in your verified achievements.

- 9 cooperating agents (Scout, Analyst, Archivist, Scribe, Critic, Publisher, Discoverer, Matcher, Curator)
- Generator-critic loop that checks every line is true
- Python, FastAPI, OpenAI, Telegram bot, Docker, Google Sheets/Drive sync
